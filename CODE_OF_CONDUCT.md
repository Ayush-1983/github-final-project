# Code of Conduct

## Our Pledge

We are committed to providing a welcoming, respectful, and inclusive environment for everyone who contributes to this project.

## Our Standards

Contributors are expected to:

- Be respectful and considerate.
- Communicate clearly and constructively.
- Accept constructive feedback.
- Focus on improving the project and helping other contributors.

Unacceptable behavior includes:

- Harassment or discrimination.
- Personal attacks or insults.
- Offensive or inappropriate comments.
- Any behavior that makes other contributors feel unsafe or unwelcome.

## Enforcement Responsibilities

Project maintainers are responsible for clarifying and enforcing the standards of acceptable behavior. They will take appropriate and fair action in response to behavior that violates this Code of Conduct.

Project maintainers may remove, edit, or reject contributions, comments, issues, or other content that does not follow this Code of Conduct.

## Scope

This Code of Conduct applies to all project contributors and participants in project-related discussions, activities, and community spaces.

## Enforcement

If you experience or witness unacceptable behavior, please report it to the project maintainers through the project's GitHub repository.

Project maintainers will review reported incidents and take appropriate action when a violation of this Code of Conduct is confirmed.

## Enforcement Guidelines

Project maintainers may use the following guidelines when responding to violations:

1. **Correction** — A private or public reminder about the expected behavior.
2. **Warning** — A warning for repeated or more serious violations.
3. **Temporary Restriction** — Temporary restriction from participating in project activities or discussions.
4. **Permanent Restriction** — Permanent removal from project participation for serious or repeated violations.
